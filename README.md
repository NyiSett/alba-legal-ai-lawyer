# Alba Legal AI Lawyer

A repository for an AI-powered legal assistant focused on helping users with legal information, document understanding, and legal workflow support.

## Overview

This project aims to provide a practical legal AI experience for:

- legal research assistance
- contract and document review support
- question answering based on legal concepts
- workflow support for legal professionals and users seeking guidance

## Features

- AI-powered legal question answering
- document and text analysis support
- structured legal information retrieval
- extensible architecture for future legal tooling
- easy onboarding for development and experimentation

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/NyiSett/alba-legal-ai-lawyer.git
   cd alba-legal-ai-lawyer
   ```

2. Create a virtual environment (Python example)
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

3. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```

4. Configure environment variables
   ```bash
   cp .env.example .env
   ```

5. Run the application
   ```bash
   python app/main.py
   ```
